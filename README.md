# Schedule Project

Initial setup of the Schedule Project, including a Next.js frontend and a NestJS backend.

## Tech Stack

- **Frontend:** Next.js, React, TypeScript
- **Backend:** NestJS, TypeScript, Node.js
- **Package Manager:** npm


## Getting Started

### Prerequisites

- Node.js (LTS version)
- npm

### Frontend Setup

```bash
cd frontend
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Backend Setup

Open a separate terminal and run:

```bash
cd backend
npm install
npm run start:dev
```

Open the backend URL shown in the terminal to verify that the application is running and returns `Hello World!`.
